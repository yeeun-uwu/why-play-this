# 3D 감각 시연

[공개 3D 시연](https://yeeun-uwu.github.io/why-play-this/microwave/prototype/)에서 전자레인지 형태, 접시와 만두의 회전, 시작/정지 버튼 반응만 확인한다. 기존 2D 게임과 독립된 임시 프로토타입이며 게임 완성본이 아니다.

- Three.js 모델과 조명, 가속/감속 회전, 클릭/Space 입력. 모션 감소 설정에서는 회전을 표시하지 않는다.
- 내부를 보기 위한 옅은 문 유리와 간단한 재질을 사용한다. 소리, 점수, 실패 연출, 배경 디테일은 포함하지 않는다.
- 검증: 18개 테스트와 Vite 빌드 통과. 내장 브라우저에서 회전 변화, 클릭 시작, Space 정지, 390×844 배치 확인.
- 2026-11-11 사이트와 함께 GitHub Pages에 공개했으며, 공개 주소 직접 접속과 3D 화면 로딩을 확인했다.
- 실기기 성능은 미검증. Three.js를 포함한 시연 번들 약 546 kB (gzip 137 kB), 빌드 크기 경고 있음.

반달형 만두 피와 양면 주름을 적용했다. 패널 버튼과 글자는 같은 3D 원근을 사용하며, 모바일 클릭 영역은 최소 44px로 유지한다. 390×844 화면에서 클릭 후 패널 정렬과 Space 정지를 재확인했다.

만두 주름은 별도의 튜브와 테두리를 제거하고 만두피 단일 표면에 통합했다. 넓은 접힘과 좁은 골이 윗부분에서 시작해 몸통으로 부드럽게 사라진다. 렌더링과 회전 중 외형을 내장 브라우저에서 확인했다.

윗부분을 얇게 집은 형태로 좁히고 주름별 폭·깊이·길이를 다르게 조정했다. 가장자리 두께가 속 부분의 10% 미만인지 기하 테스트로 확인했다. 재질에 약한 부드러운 광택을 적용했으며 버튼과 회전은 변경하지 않았다. 18개 테스트 및 빌드 통과, 내장 브라우저 외형 확인.

얇게 집은 최상단은 유지하고 바로 아래 어깨 부분에만 주름 볼륨을 보강했다. 주름 간격과 부드러운 표면은 유지한다. 18개 테스트·빌드 통과 및 브라우저 회전 중 외형 확인.
