# why-play-this — 이걸왜함

이상한 미니게임 보관함. 첫 게임은 **전자레인지 1초 전에 끄기**입니다.

게임 기획은 **개인 업적·수집 도감·자기 기록**을 중심으로 합니다. 새로운 결과 발견, 도감 완성, 개인 기록 갱신을 재도전의 목표로 삼고, 각 게임의 핵심 조작에 맞는 요소를 선택합니다.

바로 플레이: [게임 목록](https://why-play-this.pages.dev/) · [전자레인지](https://why-play-this.pages.dev/microwave/) · [의자로 퇴근하기](https://why-play-this.pages.dev/chair/)

## 로컬 개발

Node.js 22.12 이상 또는 24 이상을 사용합니다.

```sh
npm ci
npm run dev
npm test
npm run build
# dev 서버 종료 후 배포 산출물 확인
npm run preview
```

개발 서버: `http://127.0.0.1:4173/` (개발용 컴퓨터에서만 접속)

## 의자로 퇴근하기 — 재미 검증 시연

[공개 게임 플레이](https://why-play-this.pages.dev/chair/)

의자를 가고 싶은 방향으로 드래그했다 놓으면 바닥을 한 번 찹니다. 길게 끌수록 세게 밀리며, 움직이는 중에도 반대쪽으로 밀어 제동할 수 있습니다. 세 번 안에 의자 전체가 엘리베이터 안에서 멈추면 성공합니다. 책상은 고정되어 있고 쓰레기통은 밀립니다. 지나온 경로와 발구르기 위치가 결과에 남습니다.

의자와 쓰레기통의 시작 위치는 새 판마다 바뀝니다. ‘새 배치로 다시’는 다른 배치를 뽑고, 결과의 ‘같은 배치로 재도전’은 같은 시작점에서 힘과 방향을 수정할 수 있게 합니다. 시작 위치는 장애물과 겹치지 않는 통로로 제한하며 1,000개 배치의 세 번 이하 탈출 경로를 테스트합니다.

- 방 하나·의자 하나·장애물 두 개. Canvas 2D와 고정 간격 물리 계산을 사용하며 추가 의존성·외부 자산 요청은 없습니다.
- 게임 화면에 초점을 맞추고 ← → 방향, ↑ ↓ 힘, Space 발구르기, Esc 조준 취소/일시정지로 조작할 수 있습니다. 탭을 벗어나면 일시정지합니다.
- `public/chair/rules.js`는 이동·충돌·판정을, `scene.js`는 그림을, `game.js`는 입력과 화면 상태를 담당합니다. `test/chair.test.js`에서 세 번 제한, 제동, 충돌, 성공·실패, 도착 가능한 경로를 검증합니다.
- 종료하면 성공 또는 **GAME OVER · 퇴근 실패** 결과 창을 띄웁니다. 실제 경로, 이동거리, 충돌 횟수, 남은 거리와 경로 평가를 보여줍니다.
- **퇴근길 도감 32종**: 퇴근·사고·방황·손기술의 네 분류에 각 8종씩 있습니다. 일반·희귀·초희귀·전설 네 등급은 달성 난도에 따른 초기 설계값이며 실제 이용자 획득 확률은 아닙니다. 각 카드에 등급 문양·이름·조건을 표시합니다.
- 한 판에서 여러 조건을 달성할 수 있으며 유형별 최초 경로를 보관합니다. 기존 7종의 ID와 수집 기록도 유지합니다. 분류/등급/미발견 필터와 분류별 완성도를 볼 수 있고, 미발견 카드를 누르면 다음 목표가 됩니다. 목표는 현재 페이지에서 재도전할 때 유지되며 달성하거나 해제하면 사라집니다.
- 일반은 종이 티켓, 희귀는 푸른 이중 테두리, 초희귀는 보라색 장식, 전설은 금박 프레임으로 구분합니다. 새 카드 획득 시 등급별 등장 효과가 한 번 실행되고, 전설에는 금빛 문장·입자와 ‘전설 발견’ 배너를 표시합니다. 과거 카드/결과 재열람은 획득 연출을 반복하지 않습니다. reduced-motion에서는 정적 강조만 유지합니다.
- 전설 조건은 강화했습니다. 정중앙은 2회 이하·무충돌·중심 3cm, 동반 퇴근은 벽/책상 충돌 없이 둘 다 주차, 1cm 야근은 출구에 들어갔다 다시 나와 1cm 이하 차이로 실패입니다. 이전 조건으로 얻은 카드는 보존하고 당시 조건을 표시합니다.
- 엘리베이터 바닥의 중심 표시와 성공 결과의 중앙 오차로 다음 입력을 조절할 수 있습니다. 동반 퇴근의 무충돌 조건에는 쓰레기통의 벽/책상 충돌도 포함합니다.
- 충돌 대상, 제동, 이동 중 조작, 회전, 출구 통과 등을 새 판부터 관찰합니다. 역방향 입력은 감속해서 정지하며, 힘이 남아도 역주행하지 않습니다. 결과에서는 이번에 새로 얻은 카드 중 가장 높은 등급을 우선 보여줍니다.
- `records.js`는 경로 평가와 도감 저장을 담당합니다. `why-play-this:chair:routes:v1` localStorage 키를 사용하며 저장 실패 시 현재 페이지에서만 수집이 유지됩니다. 브라우저 데이터 삭제 시 사라지고 기기 간 동기화하지 않습니다. `test/chair-records.test.js`에서 판정 경계·중복 방지·손상 데이터·저장 오류를 검증합니다.
- `test/chair-rarity.test.js`와 `test/fixtures/chair-rarity-routes.json`은 32종 모두의 합법적 입력 경로, 레어도/분류 메타데이터, 기존 기록 호환과 행동 관찰을 검증합니다.
- `test/chair-layout.test.js`는 랜덤 배치의 유효성/탈출 가능성, 같은 배치 복원, 실제 쓰레기통 시작점 기준의 이동량, 강화된 전설과 예전 획득 조건을 검증합니다.
- 플레이 중 도감을 열면 일시정지하며 닫을 때 기존 정지 상태를 복원합니다. 수집한 경로를 열어보거나 결과에서 바로 재도전할 수 있습니다.
- 충돌은 원형 의자·쓰레기통과 직사각형 책상으로 단순화했습니다. 거리 표시의 1단위는 1cm로 간주하는 게임 내 척도입니다. 실제 기기 터치, 손맛과 재도전 의향은 별도 확인이 필요합니다. 랭킹·공유 업로드·소리는 넣지 않았습니다.

## 게임

- 10,000ms 동안 가동. `performance.now()`로 입력 시점의 시간을 판정합니다.
- 0 ≤ 경과 시간 < 10,000ms이면 성공. 점수는 `floor(경과 밀리초 / 10)`입니다.
- 1초 남으면 900점, 0.1초 남으면 990점, 성공 최고점은 999점입니다. 0초부터는 실패·0점.
- 기계 위의 버튼 또는 Space로 시작·정지·재도전합니다. Space 길게 누르기는 중복 처리하지 않습니다.
- 타이머는 남은 초를 올림합니다. 결과는 밀리초 단위로 올림해 소수점 3자리까지 표시하며, 기록 비교는 원래 정밀도를 사용합니다.
- 페이지가 숨겨지면 실패합니다. 그림 애니메이션 프레임과 게임 시계는 분리되어 있습니다.

## 화면과 소리

시안 B를 기준으로 생성한 2D 픽셀 아트입니다. 목록용 원본은 `public/microwave/art/kitchen-b.png`, 게임 배경은 `kitchen-empty.png`, 회전 접시는 `turntable-strip.png`에 포함됩니다. Canvas 2D의 256×384 고정 격자에 보간 없이 그려 확대하며, 청회색 부엌·주황빛 만두·문 너머 침실이 한 장면을 이룹니다. 실제 DOM 타이머와 버튼은 그림 속 조작부에 맞춰 배치됩니다. 가동 중에는 만두·접시가 8개 프레임으로 회전하고 증기가 올라옵니다. 배경 화풍에 맞춘 투명 손·가족 스프라이트를 사용합니다. 손과 버튼의 눌림을 표시하며 정지 순간 회전과 내부 조명이 멎습니다. 마지막 3초에는 화면이 최대 7% 가까워지고 안내 문구와 타이머 색이 바뀝니다. 실패 후 0.65초에 방문 불과 졸린 가족, 1.2초에 대사가 나타납니다. 성공·실패 결과와 재도전 버튼을 강조합니다. 3D 엔진이나 외부 이미지 요청은 없습니다.

소리는 기본 꺼짐입니다. 소리 켜기를 누르면 Web Audio를 사용합니다.
- 가동: 60Hz와 배음의 모터 진동, 필터링한 팬 노이즈, 기계식 딸깍음을 합성한 2초 루프.
- 시작·정지: 짧은 릴레이/잠금장치 소리.
- 실패: 2.45kHz 중심의 전자레인지식 3회 알람.
- 정지/음소거 시 가동음을 종료하고, 도중에 소리를 켜면 경과 시간에 맞춰 루프를 재개합니다.

실제 기기를 녹음한 파일이 아닌 절차적 합성음입니다. 기기·스피커별 음색과 볼륨은 다를 수 있습니다.

그림을 불러오지 못하면 간단한 화면으로 게임을 계속할 수 있습니다. reduced-motion 설정이면 접시·증기 움직임과 화면 확대를 멈춥니다. DOM 버튼의 키보드 focus와 결과 live region을 유지합니다. 카운트다운은 매초 낭독하지 않습니다.

## 코드와 검증

- `public/microwave/rules.js`: 점수·시간·저장 데이터 검증. 기존 테스트 유지.
- `game.js`: 입력, 타이머, 결과, 저장, 소리 상태.
- `scene.js`, `scene-layout.js`: Canvas 2D 픽셀 연출과 반응형 버튼 좌표.
- `synthesis.js`, `audio.js`: 결정론적 소리 샘플 생성과 Web Audio 재생/정리.
- Node 테스트: 타이머 경계, Space 반복, 늦은 입력, 탭 숨김, 저장 실패, 소리의 범위·무음 구간·루프·음소거.

게임 배경 PNG는 약 1.63MB, 회전 스프라이트는 약 563kB, 손·가족 원본은 합계 약 2.48MB이며 목록용 원본은 약 1.61MB입니다. 이미지가 없으면 간단한 화면으로 플레이할 수 있습니다.

## 개인 기록 저장

최고 기록은 localStorage의 `why-play-this:microwave:best:v1`에 남은 밀리초로 저장합니다. 동점이면 남은 시간이 더 적은 기록을 유지합니다. 저장이 차단되면 현재 페이지에서만 기록을 유지합니다. 브라우저 데이터 삭제 시 사라지며 다른 기기로 동기화하지 않습니다.

현재는 게임별 브라우저 로컬 저장소를 사용하며, 전체 이용자 랭킹은 기본 기획 범위에 포함하지 않습니다. 별도 계정·게임 서버·DB 없이 정적 사이트로 운영합니다. 기록 백업과 기기 간 동기화는 구현되어 있지 않습니다.

## Cloudflare Pages 배포

2026-11-12에 Cloudflare Pages의 `why-play-this` 프로젝트로 공개해 블로그 도메인과 분리했습니다. HTML·CSS·JavaScript·이미지만 올린 무료 정적 호스팅이며, Functions·DB·유료 부가 기능은 사용하지 않습니다.

공개 사이트: [이걸왜함](https://why-play-this.pages.dev/)

Vite는 목록, 전자레인지, 전자레인지 3D 시연, 의자 퇴근 시연의 HTML 진입점을 `dist/`로 빌드합니다. 자산 경로는 상대 경로(`base: './'`)를 사용하며, 게임별 `index.html`을 제공하므로 `/chair/`, `/microwave/`로 직접 접속할 수 있습니다.

배포는 **수동 Direct Upload** 방식입니다. 게시 승인 후 `npm ci` → `npm test` → `npm run build`를 실행하고, Cloudflare 대시보드의 `why-play-this` 프로젝트에서 `dist/` 폴더 또는 그 내부 파일을 담은 ZIP을 프로덕션 배포로 업로드합니다. 소스·개발 문서·`node_modules/`는 업로드하지 않습니다. Git push만으로 Cloudflare 사이트가 갱신되지는 않습니다.

테스트 51개와 빌드가 통과했습니다. 새 공개 주소에서 게임 목록, 전자레인지 시작/정지, 의자 입력·일시정지·재시작·도감, 각 게임과 3D 시연의 직접 접속을 확인했습니다. 의자 화면은 320px에서도 가로 넘침이 없음을 확인했습니다.

이전 GitHub Pages 배포는 2026-11-11에 완료했습니다. 기존 `.github/workflows/pages.yml`은 수동 실행 전용으로 남아 있으며 Cloudflare 배포와는 별개입니다. [이전 배포 기록](https://github.com/yeeun-uwu/why-play-this/actions/runs/42967216999) · [Cloudflare Direct Upload 안내](https://developers.cloudflare.com/pages/get-started/direct-upload/)

실제 모바일 터치·스피커 청음·스크린리더는 아직 별도 확인 대상입니다. 로컬 개발 주소나 이전 GitHub Pages 주소의 최고 기록·도감은 새 도메인으로 자동 이전되지 않습니다.
